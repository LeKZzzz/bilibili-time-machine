# B 站按时间过滤

这是一个同时提供 Tampermonkey 用户脚本和 Chrome MV3 扩展的 B 站时间过滤工具。它按本地截止时间 `T` 严格保留发布时间早于 `T` 的当前内容；无法确认时间的内容会隐藏。它过滤当前可获取的内容，不恢复已删除内容、历史页面快照或历史推荐排序；弹幕首版支持 XML，protobuf 弹幕尚未实现。

## 构建

需要 Node.js 和 npm。安装依赖后运行：

```powershell
npm install
npm run build
```

发布产物位于：

- `dist/userscript/bilibili-time-filter.user.js`
- `dist/extension/`

开发排查版本会自动输出脱敏控制台日志，构建命令为：

```powershell
npm run build:dev
```

开发产物位于 `dist/dev/userscript/` 和 `dist/dev/extension/`。日志使用 `[时光机]` 前缀，记录配置、原生日期范围、网络过滤统计、逐卡判定和补请求状态，不上传数据。

## 使用

在 B 站支持页面打开页面内的“时光机”面板，设置本地截止日期和时间后启用过滤。支持的主机包括：

- `www.bilibili.com`
- `search.bilibili.com`
- `space.bilibili.com`
- `t.bilibili.com`

安装用户脚本时加载 `dist/userscript/bilibili-time-filter.user.js`。安装扩展时在 Chrome 的开发者模式中加载 `dist/extension/`，然后刷新 B 站页面。

搜索页启用过滤后，如果当前页保留下来的结果少于原页容量的一半，工具会通过 B 站原生分页请求最多补取后两页，按 BV 号去重并把可展示结果前移；补页结束后恢复当前页和 URL。补页失败时继续使用逐页过滤。

首页还支持可选的“收藏标签首页补位”。在“高级设置”中显式开启后，先刷新收藏夹列表并在多选框中选中一个或多个收藏夹；工具按收藏视频 tag 的频次和最近收藏时间生成候选，只填充因时间过滤隐藏的首页空位。候选会按 B 站 UID 分区缓存在 IndexedDB 中，收藏标签快照、搜索候选和补位去重历史分别使用固定 TTL 与数量上限；缓存不足时最多对 5 个高分 tag 各搜索 1 页。关闭功能或未选收藏夹时不会读取收藏内容或发起标签搜索。

补位先让不同标签各提供一条候选，再按标签分数分配剩余空位；某个标签的缓存足以填满时，仍会在请求预算内补取本轮缺席标签的候选。起始标签随快照保存并在后续批次轮换，只有一个空位时也能轮流展示不同来源；其他标签没有符合时间和去重条件的结果时，使用已有可用候选补齐。

每个标签分别按“第 1 页 → 第 2 页 → … → 末页 → 第 1 页”循环，候选不足时在后续轮次继续，遇到空页也在下一轮回到第 1 页。页码和起始标签在收藏快照有效期内跨刷新复用；手动刷新收藏标签时保留仍有效的标签进度，页码回绕保留已推送视频的去重历史。同一批原生卡片和设置只执行一轮自动搜索，轮播、预览或面板变化不会反复启动；加载骨架不计作补位空位。

收藏读取默认最多 3 个收藏夹、每夹按收藏时间倒序读取 50 条视频；上限可分别设置为 1–10 个收藏夹和每夹 1–200 条。收藏快照在读取时检查 24 小时有效期，过期后重建，也可点击“立即刷新收藏标签”；“已提交收藏标签刷新请求”表示请求已提交，不代表标签读取已经完成。当前没有独立的后台定时刷新任务。

补位卡片使用首页原生外观，封面、标题、UP 主、播放统计和时长使用候选视频的信息；“收藏标签补位：标签名”标记说明本轮实际命中的收藏标签。点击“查看当前标签”可弹出当前收藏标签列表，并显示每个标签命中的收藏视频数。搜索标题中的高亮标签和 HTML 实体会在显示前转换为纯文本，已有缓存候选也会重新清理。更新扩展产物后，需要在扩展管理页重新加载当前使用的 `dist/extension/` 或 `dist/dev/extension/`，再刷新 B 站页面。

候选保留 7 天、每账号最多 500 条；补位去重历史保留 30 天、每账号最多 1000 条。跨标签页或刷新复用要求页面同源，不同 B 站子域名不共享缓存。当前缓存由补位控制器发起的搜索填充，尚未收集用户搜索页已加载的结果。旧缓存缺少 UP 主或统计字段时，对应位置留空；IndexedDB API 不可用时只使用当前页面内存。

遇到补位问题时可先检查：

- 首页未补位：确认当前位于 `www.bilibili.com/`，时间过滤和收藏标签补位都已开启、已选择收藏夹，并存在被时间过滤的卡片；没有符合截止时间且未推送过的候选时仍会留空。
- “过滤器无法验证当前内容，相关内容已隐藏。”表示普通卡片时间校验或补请求失败；“收藏标签补位失败，本轮已停止。”表示收藏补位链路失败，两者都继续执行严格时间过滤。
- 更新后仍显示旧标记或重复封面：在扩展管理页重新加载当前使用的生产或开发目录，再刷新 B 站页面；两类产物位于不同目录。

## 验证

```powershell
npm run typecheck
npm test -- --run
```

当前构建还提供以下单独命令：

```powershell
npm run build:userscript
npm run build:extension
npm run build:userscript:dev
npm run build:extension:dev
```

发布构建不包含项目诊断日志；开发构建只向当前浏览器控制台输出脱敏日志。
